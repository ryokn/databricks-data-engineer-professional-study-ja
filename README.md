Associateの学習と公式トレーニングを終え、**2026年11月9〜15日ごろに日本語で受験する方**を想定した、非公式のオリジナル教材です。基礎解説より、要件からの使い分け・本番運用・ひっかけに集中します。

## 最初に確認：受験日とバージョン

**日本語公式ガイドは、現行試験を2026年11月19日まで、新試験への切り替えを11月20日と明記しています。**
- 来週の日本語受験は、現行の**採点59問・120分・10ドメイン**を対象にします。
- 新試験は60問・120分・9ドメイン、**英語のみと記載**。日本語の再提供日は要確認。
- 新ガイド（英語）の公開日／更新日は2026-10-09。日本語PDFはURLが2026-10ですが、本文に数値版番号・更新日の明記がなく要確認です。
- 日本語PDFの現行配点は合計106%になり、公式Webページの配点と食い違います。本教材は**Webページの合計100%の配点を暫定採用**。共有5%（PDF10%）・モデリング6%（PDF7%）の不一致をガイド0章で記録しています。
- 日本語Web本文の「90分」は、同ページFAQ・日本語PDF両列・英語ページの「120分」と不一致です。120分を採用しつつ、予約時に確認してください。
- 日程が11/20以降に変更された場合、**現行模試だけで完結しません**。ガイド0.4の新範囲へ学習を切り替え、提供言語・予約条件を確認してください。
- 切り替え日の適用時刻は要確認。試験日の2週間前と予約確定時に公式情報を再確認してください。

## HTMLの開き方（private GitHubでも同じ）

GitHubはリポジトリ内のHTMLをそのまま模試として実行しません。
1. サインイン済みのブラウザで対象HTMLファイルを開く。
2. **Raw / Download raw file（生ファイルのダウンロード）**を使い、`.html`として保存する。Raw画面にソースが表示される場合はそこからダウンロードする。
3. 保存したファイルをChrome・Edge・Safari・Firefox等で開く。ZIPをダウンロードした場合は展開して開く。
4. 全機能にJavaScriptが必要。採点に通信や外部ライブラリは不要。根拠リンクを開く時だけ通信が発生する。

privateリポジトリを閲覧可能な人だけがダウンロードできます。公開Pagesへの変更は不要です。MDとHTMLを同じフォルダへ置くと相互リンクも使えます。進捗は同じブラウザに保存され、file://やブラウザ設定によって保存できない場合があります。その場合も採点は使えます。重要な進捗はJSON出力し、別端末ではJSON復元してください。

## 1週間の使い方

2〜3時間/日の計画案です。**短縮版は★の見出しだけ**＋誤答の根拠確認（約60〜90分/日の提案）。公式所要時間や合格保証ではありません。

| 日 | 集中テーマ | 短縮版 |
|---|---|---|
| 1 | 受験版の確認、模試40問で現状測定、誤答を分類 | ★模試＋弱点の章を特定 |
| 2 | コード開発、ST/MV、CDC、制御フロー、テスト | ★ST/MV・CDC・再試行・テスト |
| 3 | 性能診断、CDF、join/window、品質隔離 | ★比較表・CDF・NULL隔離 |
| 4 | UC、行/列制御、匿名化、消去と継承 | ★USE/SELECT・マスク・削除・継承 |
| 5 | 監視、ログ選択、repair、Bundles/CI/CD | ★観測源・repair・validate/deploy/run |
| 6 | 取り込み、モデル、共有/Federation、模試再演習 | ★使い分け表＋説明できない誤答 |
| 7 | 公式サンプルの観点、直前チェック、受験環境 | ★直前チェック。教材追加を止める |

同じ問題の正答番号を暗記せず、各選択肢がどの制約を満たすかを説明します。公式合格点は非公開です。本模試には合格／不合格判定を設けていません。

## 生成・検証

```bash
# Python 3標準ライブラリで再生成
python3 build/build.py
# 問題の編集元からデータも再生成する場合
python3 build/author_questions.py
python3 build/build.py
# Node.jsでHTML内の実際のJSを検証（npm依存なし）
node build/test.js
```

- 配点に合わせた40問、問題IDの一意性、正解位置の均等性を確認。
- Node VM＋DOMハーネスで**全160選択肢の選択・採点・解説**、全問正解40/40、全問不正解0/40、分野別集計、復元、変更後の再採点、フィルタ、リセット確認、JSON入出力、保存不可時の継続を検証済み。
- HTML構文解析で単一script、外部script/CSSなし、viewport・日本語指定・ID重複なしを確認。
- 実ブラウザでの画面レイアウト・操作の検証は未実施。利用するブラウザで開き、最初の1問と再読込で確認してください。
- Databricks実環境でコードを実行・デプロイしたわけではありません。例は専用の演習環境で検証してください。
- 公式資料・演習リンクを含む**36 URLにHTTP 200**を確認。記録は `build/source-checks.json`（確認日時はJSTオフセット付き）。任意の再確認スクリプト `build/check_links.py` は `requests` が必要です。
