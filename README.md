## 学習の進め方

| 読者 | 進め方 |

### 1週間集中（基礎を学習済みの方）

期間・時間は学習計画の提案であり公式所要時間ではありません。通常2〜3時間/日、短縮版は★だけと誤答の根拠確認を優先する案です。

| 日 | 通常版 | ★短縮版 |
|---|---|---|
| 1 | 版確認・模試・誤答分類 | 弱点の項目を特定 |
| 2 | 1章：開発・CDC・制御・テスト | ST/MV・CDC・環境・テスト |
| 3 | 2・3章：性能・変換・品質 | 比較表・CDF・NULL隔離 |
| 4 | 5・8章：保護・削除・継承 | USE/SELECT・マスク・保持 |
| 5 | 4・6章：監視・修復・配備 | 診断源・repair・Bundle |
| 6 | 7・9・10章、再演習 | 入力・粒度・共有の使い分け |
| 7 | 公式サンプル論点・直前確認 | 直前チェック。教材を増やさない |

### 3〜4週間（初学者から）

| 週 | 範囲 | 到達点 |
|---|---|---|
| 1 | 用語・1・7章 | 状態、依存、テスト、取り込みを説明 |
| 2 | 3・2・9章 | 品質・粒度・配置と性能を分離して判断 |
| 3 | 5・8・10章 | 保護・保持・継承・共有を設計 |
| 4 | 4・6章、模試、公式サンプル | 監視・診断・修復・配備を説明 |

3週間なら第3・4週の演習を並行。現行試験の期限を越える場合は新試験付録へ切り替え、受験言語・範囲を再確認してください。

## privateリポジトリからHTMLを使う

サインインしてHTMLを開き、**Raw / Download raw file**で`.html`として保存し、ブラウザで開きます。ZIPの場合は展開します。GitHubのソース表示画面は模試として動きません。公開Pagesへの切替は不要です。

HTMLは単一ファイルで採点に通信・外部依存は不要。公式根拠へ移動する時は通信が必要です。JavaScriptを有効にしてください。進捗は同じブラウザに保存されますがfile://や保存設定によって異なるため、重要な記録はJSON出力し、別端末では復元します。

## 生成・検証

```bash
python3 build/author_questions.py
python3 build/build.py
node build/test.js
# 任意。requests が必要
python3 build/check_links.py
```

`questions.json` が問題文の編集元です。`author_questions.py` は問題文を書き換えず、分野配分・対応表・ガイドの節が食い違っていないかを確認します。HTMLの見出し・進捗の最大値・テストの期待問数は、生成時のデータから決まります。

対応表は全54行（45学習目標＋8親項目＋1原文の継続断片）に見出しと少なくとも1問があることを検証します。対応があることは、一問でその項目の全仕様を検証できるという意味ではありません。

進捗の保存キーは `dep-study-ja-current-20261107-v2` です。旧40問パックのキー `dep-study-ja-current-20261107-v1` が残っている場合は、同じ問題番号の解答だけを引き継ぎ、追加問題は未回答にします。旧キーで書き出した進捗JSONも同じ規則で復元できます。

確認日 2026-11-07（JST）の結果:

- オリジナル60問。配分はコード13、取り込み5、変換品質6、共有4、監視6、性能8、セキュリティ6、ガバナンス4、デバッグ配備5、モデル3。
- `node build/test.js` で、埋め込みJSの全240選択肢の選択・採点・解説、全問正解60/60、全問不正解0/60、10分野それぞれの満点、再読込、選び直し、フィルタ、リセット確認、現行キーと旧40問キーのJSON入出力、壊れたJSON、保存不可時の継続、対応表54行がそれぞれ1問以上を確認。
- ブラウザで単一HTMLを開き、60問すべてを正解にして「全選択を採点」し、分野別の表が配分どおり満点になることを確認。
- ガイド・README・模試が参照する公開リンク61件は `build/source-checks.json` でHTTP 200を確認。

Databricks上のコード例は専用環境で権限・Runtime・機能の提供条件を確認して使用してください。実機を使えないPreview等は公式説明と設計で補います。合格点は非公開で、模試の正答率を公式合格判定とはしません。
